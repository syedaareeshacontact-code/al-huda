# Instagram profile photo

The Instagram onboarding page currently uses `syed-areesha.jpeg`, supplied for Syed Areesha.

If the profile photo changes:

1. Replace `syed-areesha.jpeg` with an optimized square image using the same filename, or update
   the image path in `src/components/instagram/instagram-landing.tsx`.
2. Add the confirmed profile URL to the Instagram footer and social-trust section. Do not add a
   verification badge unless the account's verification status has been confirmed.
